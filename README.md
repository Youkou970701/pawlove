# PawLove - 情侣双人养宠 Web App

## 核心需求
- 双人共养一只虚拟狗狗（从蛋开始孵化）
- 蛋→幼犬→成犬 进化路线
- 实时同步：一方操作，另一方立刻看到
- Web first，后续打包成 PWA/移动端

## 技术栈
- Vite + React 18 + TypeScript
- Tailwind CSS
- Express + Socket.io（实时通信）
- MongoDB（数据持久化）
- 后续支持 PWA 打包

## 核心玩法（蛋孵化制）
1. 初始：获得一颗"狗蛋"，需要两人每天互动才能破壳
2. 破壳期：每天完成情侣任务积累 warmth 值，达到阈值后破壳
3. 幼犬期：喂食/玩耍/清洁/睡觉四维指标管理
4. 成犬期：解锁装扮、小屋装饰、双人小游戏

## 情侣互动功能
- 每日问答（了解对方）
- 默契挑战
- 双人相册
- 心情日记
- 纪念日提醒

## 实时同步机制
- Socket.io room：每对情侣一个独立房间
- 操作即时广播
- 离线数据 MongoDB 持久化
